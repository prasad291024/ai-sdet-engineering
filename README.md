# AI-SDET Engineering

A hands-on learning journey from SDET/automation engineering to AI Quality Engineering.

## Objective

This repository documents the practical progression toward becoming an AI-focused SDET / AI Quality Engineer.

The program focuses on:

- AI and ML foundations
- LLM engineering
- AI application development
- LLM evaluation
- RAG quality engineering
- AI agent testing
- AI security
- Observability
- CI/CD quality gates
- Production AI quality engineering

## Learning Philosophy

> Learn → Understand → Implement → Test → Break → Debug → Evaluate → Commit → Push → Review → Improve

The goal is not simply to use AI tools or frameworks.

The goal is to understand enough to **build, test, evaluate, secure, debug, and operate AI systems**.
